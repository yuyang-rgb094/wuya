# LLM as Mapper + 学科先验分布校准

采用混合架构将 5 维评分映射到论文估计分区：LLM 基于跨学科知识进行推理，输出 P_llm(分区|评分,学科)；同时从 Spring Rank 分区表提取该学科的先验分布 P0(分区|学科)；最终通过贝叶斯校准（P_final ∝ P_llm × P0）或线性插值得到稳健估计。选择此方案是因为纯统计回归需要大量标注数据，纯规则引擎主观性太强，而 LLM 的跨学科知识恰好弥补了学科差异的复杂性，先验分布则作为"事实锚点"防止 LLM 在陌生学科上乱猜。

## 关键设计要点

- **先验提取**：从分区表按学科统计 Q1-Q4、A-D 分布，学科粒度可用 DB学科 或 DB大类，样本不足时回退到上级分类
- **Prompt 工程**：包含 5 维评分标准说明 + 跨学科 few-shot 示例 + 先验分布数据，要求 LLM 输出推理链 + 估计分区 + 置信度
- **一致性保障**：temperature 设为 0.1 以下，多次采样取众数，相同 (评分,学科) 结果缓存复用
- **校准策略**：贝叶斯后验融合或简单线性插值 α·P_llm + (1-α)·P0，α 可设为 0.6~0.8 优先信任 LLM 推理
