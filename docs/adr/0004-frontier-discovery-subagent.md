# 独立前沿发现 Sub-agent + 分层定位架构

采用分层架构将论文定位到知识网络：路径 A（LLM as Mapper + 先验校准）用于快速筛选和跨学科比较；路径 B（DEA 效率分析）用于深度推荐和置信度评估，条件为目标期刊有足够历史数据。同时引入独立的"前沿发现 Sub-agent"，在与作者/编委的交互过程中动态发现和归纳领域前沿节点，逐步从局部前沿积累形成通用前沿面。

## 关键设计要点

- **路径 A（快速）**：LLM 基于 5 维评分 + 学科先验分布，直接推理估计分区，temperature 0.1 以下保证一致性
- **路径 B（深度）**：将 5 维评分转换为投入（方法漏洞、证据不足）和产出（创新性、应用前景），用目标期刊历史论文构建 DEA 前沿面，Bootstrap 估计置信区间
- **交叉验证**：两路径结果一致时高置信度推荐，矛盾时触发 RAG 解释原因
- **前沿发现 Sub-agent**：独立运行，输入为交互过程中的论文特征和编委反馈，输出为领域前沿节点归纳，积累形成可复用的前沿面知识库
