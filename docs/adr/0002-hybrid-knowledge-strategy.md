# 混合知识策略：Prompt 内化"道" + RAG 调用"术"

Sub-agent 采用混合知识注入策略：System Prompt 内嵌从经典理论提炼的评价原则（"道"），作为内化判断框架；RAG 检索原文中的具体论证、案例、金句（"术"），用于支撑评审意见和改进建议。选择此方案是因为产品核心价值观强调"成全"而非"评判"——当需要真正帮助学者改进稿件时，引用波普尔、库恩等经典理论的原文金句来指导修改，比干巴巴的原则更有说服力和启发性。

## 关键设计要点

- **Prompt 层**：承载理论综述中提炼的"评价维度 → 底层原理 → 核心论断"三层结构，确保 Sub-agent 始终有判断框架
- **RAG 层**：索引所有经典文献原文，按"理论家 + 核心概念"组织 chunk，支持精准检索
- **触发逻辑**：评审意见生成阶段，当 Sub-agent 需要"解释为什么"或"给出改进建议"时，触发 RAG 检索相关原文作为支撑
